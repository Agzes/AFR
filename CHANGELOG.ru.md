# Changelog

Все заметные изменения проекта AFR. Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии - по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-10-25

Первый ранний публичный релиз.

### Добавлено

- Редактор конфигов с вкладками: профили, отыгровки (шаги, задержки S100...S4000, тексты по родам), параметры, окна быстрых действий, бинды.
- Меню действий: список, радиальное, плитки + переключение вида одной кнопкой.
- Библиотека конфигов: каталог, теги, фильтры (Все/Установленные/Обновления), установка/обновление/удаление, офлайн-кэш, diff-обновления.
- Хоткеи с модификаторами (Ctrl/Alt/Shift), окна быстрых действий с биндами, обнаружение конфликтов биндов.
- HUD: статус, прогресс отыгровки, уведомления.
- AutoChat: многострочный текст в отыгровку.
- Темы интерфейса (Текущая, Vesper, Сезонная - через сервер) + полный редактор цветов, экспорт/импорт темы; сезонные темы через `production-args.json`.
- Импорт/экспорт профилей (файл/буфер обмена) + подтверждение и предупреждение о проверке источников.
- Импорт отыгровок из конфига QuickMenu (файл/вставка JSON).
- Локализация ru/en; выбор языка при первом запуске.
- Обучение и быстрая настройка при первом входе.
- Проверка обновлений мода и объявления.

### Движок действий

- Методы шага: отправка в чат/команду или открытие строки ввода с текстом.
- Переменные: `{Name}`, `{FirstName}`, `{LastName}`, `{Role}`, `{Param:id}`, `{A|B|C}`, служебные клавиши.
- Задержки "до"/"после" шага (S-коды) и общий множитель.
- Авто-стоп (экран/смерть/мир), ForceStop, продолжение с прерванного шага, кулдаун на действие и по умолчанию, уведомления о старте/конце, watchdog.

### Прочее

- Понижены минимальные требования: Fabric Loader 0.14.23+, Fabric API 0.91.1+.
- Лицензия GPL-3.0-only.
- Веб-бандл `web/` (сайт + API библиотеки + просмотрщик конфига) и локальный сервер `bash web/serve.sh`.
