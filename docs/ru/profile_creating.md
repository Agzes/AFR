# Гайд: создание профиля AFR

Руководство от пустого профиля до готового к публикации конфига.

---

## 0. Профиль

Профиль - это набор отыгровок, параметров и окон, сохранённый в `config/afr/profiles/<id>.json`.

Профили бывают:

- **локальные** (`source: local`) - созданы вами, полностью редактируемы;
- **библиотечные** (`source: library`) - скачаны из библиотеки; метаданные только для чтения, есть кнопка "Создать локальную копию" (fork).

## 1. Редактор

- Клавиша редактора (по умолчанию **Right Shift**, меняется в базовых настройках Minecraft) или команда `/afr`.
- Вкладка **Профили** -> поле "Новое имя профиля" -> **Создать** (пустой) или **Копия** (копия активного).

## 2. Метаданные (необязательно)

В карточке "Метаданные" заполните:

- **Авторы** (через запятую) - например `ВашНик, Соавтор`;
- **Редакторы** (через запятую) - те, кто помогал с правками;
- **Описание** - что за набор отыгровок;
- **Теги** (через запятую) - `hospital, медицина, rp` (используются для поиска в библиотеке).

Метаданные библиотечных профилей заполняет автор - они не редактируются локально.
Метаданные не обязательны при локальном использовании. При публикации в библиотеку автор, описание и теги должны быть заполнены.

## 3. Параметры (необязательно, ситуативно)

Вкладка **Профили** -> карточка "Параметры" -> **Изменить**:

- **id** - латиницей, без пробелов (например `price`);
- **label** - как показать пользователю;
- **тип** - `Текст` или `Число`;
- **значение** - по умолчанию.

В тексте шага используйте `{Param:id}` (например `{Param:price}`).

## 4. Отыгровки и шаги

Вкладка **Отыгровки** -> выберите действие или **Новое действие**.

У действия:

- **Название**, **Описание**, **Категория**, **Кулдаун** (мс), **Избранное**;
- **Иконка** (любой предмет Minecraft);
- **Шаги** - сами отыгровки.

Каждый шаг:

| Поле  | Значение                                                                                        |
| ----- | ----------------------------------------------------------------------------------------------- |
| Тип   | **Универсальная** (один текст) или **Разделенный по родам** (отдельный текст для женского рода) |
| Метод | **Отправить** (сразу в чат/команду) или **Ввод** (открыть строку чата с текстом)                |
| до    | задержка ПЕРЕД шагом (S-код)                                                                    |
| после | задержка ПОСЛЕ шага (S-код)                                                                     |
| Текст | сам текст, с переменными                                                                        |

**S-коды** - это миллисекунды: `S100` = 0.1с, `S300` = 0.3с, `S1000` = 1с. Есть общий множитель в настройках профиля.

**Команды**: если текст начинается с `/`, он отправится как команда (без слэша), иначе как сообщение.

## 5. Переменные

Подставляются в текст шага при выполнении:

| Переменная                                 | Значение                       |
| ------------------------------------------ | ------------------------------ |
| `{Name}` / `{RPName}`                      | имя персонажа из настроек      |
| `{FirstName}` / `{LastName}`               | части имени                    |
| `{Role}` / `{Position}`                    | должность                      |
| `{Param:id}` (или `{id}`)                  | параметр профиля               |
| `{A\|B\|C}`                                | случайный вариант из списка    |
| `{Left} {Right} {Up} {Down} {Tab} {Space}` | служебные клавиши (нажимаются) |

Неизвестные `{...}` остаются как есть - их подсветит **Проверить**.

## 6. Окна быстрых действий

Вкладка **Профили** -> карточка "Окна" -> **Окно**:

- **Название** и **Стиль**: `Список` / `Плитки` / `Радио`;
- для списка - отметьте отыгровки (клик по чипу);
- для плиток - задайте сетку и кликните по ячейке, чтобы выбрать отыгровку;
- окну можно назначить **бинду** (вкладка **Бинды**).

## 7. Бинды

Вкладка **Бинды**:

- **Системные**: Меню, Стоп, Перезагрузка;
- **Окна**: клавиши окон;
- **Отыгровки**: клавиша на каждое действие.

Клик по полю -> нажмите клавишу (с модификаторами Ctrl/Alt/Shift). Конфликты подсвечиваются в карточке «Конфликты биндов». «Сделать базовыми» переносит текущие бинды в профиль.

## 8. Проверка

Вкладка **Отыгровки** -> **Проверить**: подсветит дублирующиеся имена, пустые шаги и неизвестные переменные. Карточка показывается только когда есть замечания.

## 9. Экспорт / импорт

Вкладка **Профили**:

- **Экспорт** - сохраняет `config/afr/exports/<id>.json`;
- **Копировать** - JSON в буфер обмена;
- **Импортировать** - окно с вставкой JSON или загрузкой файла (с предупреждением о доверии источнику).

## 10. Сохранение

Редактор сохраняется **только по кнопке «Сохранить»**. Пока есть несохранённые правки, вверху справа горит `⚠ не сохранено`. При закрытии спросит, сохранить или выйти без сохранения.

## 11. Запрос на публикацию

Когда профиль готов:

1. Убедитесь, что заполнены метаданные (авторы, описание, теги).
2. **Экспорт** профиля в файл.
3. [Создайте issue на GitHub](https://github.com/Agzes/AFR/issues/new/choose) или напишите автору в Discord.
   (в скором времени это заменится на автоматического Discord-бота)

После одобрения конфиг появится в библиотеке: пользователи смогут установить его в один клик, а обновления подтянутся автоматически через единый API.
